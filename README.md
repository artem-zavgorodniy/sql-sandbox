# SQL-пісочниця «Зелена Полиця»

Навчальна SQL-пісочниця до курсу «Бізнес-інформатика» (ДУІКТ, спеціальність 073 «Менеджмент»).

**▶ Відкрити пісочницю: https://artem-zavgorodniy.github.io/sql-sandbox/**

Сторінка працює повністю в браузері: база даних і рушій SQL вбудовані в `index.html`. Реєстрація не потрібна, дані нікуди не надсилаються, змінити базу для інших неможливо — кнопка «Скинути базу» повертає її до початкового стану.

## Дані

Інтернет-магазин «Зелена Полиця» — вигадана компанія, усі дані згенеровані для навчання й не містять інформації про реальних людей.

| Таблиця | Що зберігає | Рядків | Первинний ключ | Зовнішні ключі |
|---|---|---|---|---|
| `kliyenty` | клієнти: ім'я, місто, дата реєстрації, канал залучення | 360 | `customer_id` | — |
| `tovary` | товари: назва, категорія, ціна, собівартість, постачальник | 36 | `product_id` | — |
| `zamovlennya` | замовлення: дата, кількість, сума, доставка, статус, способи доставки й оплати | 2377 | `order_id` | `customer_id` → `kliyenty`, `product_id` → `tovary` |

Період: вересень 2025 — серпень 2026.

## Файли

- `index.html` — пісочниця.
- `zelena_polytsia.db` — та сама база у форматі SQLite, щоб відкрити її в будь-якому іншому інструменті, наприклад DB Browser for SQLite чи sqliteonline.com.

## Технічно

Рушій — [sql.js](https://github.com/sql-js/sql.js) 1.12.0 (SQLite, скомпільований у JavaScript), вбудований у сторінку без зовнішніх залежностей. Шрифти IBM Plex підвантажуються з Google Fonts; без інтернету сторінка використовує системні шрифти.
